# Low-Level Design (LLD)

Detailed software design focused on implementation and maintainability.

## Topics

- Object-oriented design and SOLID principles
- UML class and sequence diagrams
- Design patterns and clean code
- Interfaces, classes, domain models, and responsibilities
- API contracts, validation, errors, and persistence boundaries
- Concurrency, testing, and extensibility
- LLD case studies and coding exercises

## Design note template

For each problem: requirements → entities and responsibilities → interfaces → class/sequence diagrams → implementation → tests → trade-offs.
