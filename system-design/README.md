# System Design

Cross-domain system design knowledge for designing reliable, scalable, maintainable software systems.

## Scope

- Requirements and capacity estimation
- High-level and low-level design
- Architecture patterns and trade-offs
- Scalability, availability, reliability, and performance
- Caching, queues, messaging, APIs, and data flows
- Distributed systems and consistency
- Security, observability, and resilience
- End-to-end system design case studies

## Organization

Keep cross-cutting design knowledge here. Deep implementation details belong to their respective domains under [`domains/`](../domains/), and can be linked from system design notes.

Start with case studies and add subfolders only when needed.
