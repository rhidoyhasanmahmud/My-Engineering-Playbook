# High-Level Design (HLD)

Cross-domain architecture design at the system level.

## Topics

- Functional and non-functional requirements
- Capacity estimation and traffic patterns
- Architecture diagrams and component boundaries
- APIs, data flow, storage, caching, messaging, and load balancing
- Scalability, availability, reliability, and security
- Architecture trade-offs and design case studies

## Design note template

For each system: requirements → estimates → architecture → data flow → scaling → failure modes → trade-offs.
