## SQL topics you will learn

| Topic | What you can do after Part 01 | Scenarios |
| --- | --- | --- |
| Database and table design | Create a PostgreSQL database and tables. Choose data types, primary and foreign keys, unique rules, defaults and checks. | 1, 4 |
| Data changes and transactions | Insert, update and delete rows. Use a transaction, savepoint and rollback to test or undo a change. | 2, 11 |
| Filters and joins | Filter, sort and page a result. Join related tables and keep rows that have no match. | 3–4 |
| Reports and aggregates | Use counts, totals, averages and conditional counts. Keep empty groups and avoid duplicate counts. | 5 |
| Subqueries and set operations | Find missing records, compare groups and combine query results. | 6 |
| SQL functions and advanced queries | Clean text, work with dates and JSON, use CTEs, rank rows and compute running totals. | 7–8 |
| Imports, cleanup and performance | Import and clean data, normalize tables, work with views and indexes, and read an execution plan. | 9–10 |
| Routines, security and recovery | Practice procedures, triggers and cursors. Use parameterized queries, read-only access and backup/restore. | 11–12 |
