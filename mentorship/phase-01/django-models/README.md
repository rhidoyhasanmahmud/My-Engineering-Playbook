# Phase 01 · Part 2 — Django Models Project

**Project:** Helpdesk Ticket System  
**Prerequisite:** Complete [Part 1 — SQL Foundations and Interview Practice](../README.md).

Build the Helpdesk data layer in Django with PostgreSQL. Demonstrate all features with Django shell, a management command or automated tests. The models you build here will support the API in the next phase.

Start with the [Django model layer](https://docs.djangoproject.com/en/6.1/#the-model-layer). Use the documentation version that matches the Django version installed in your project.

## Feature and learning map

| Feature | Build | Learn and reference | Done when |
| --- | --- | --- | --- |

| **F04 · Track status changes** | Add `StatusChange`. | **F05 · Find tickets in the agent queue** | Build reusable queryset methods for open tickets, unassigned tickets and an agent's queue. ## Work and review

- One student starts with ticket and routing features. The other starts with tags and comments once the ticket model is available. Review each other's migrations and rotate ownership for the later features.
- Use fixtures with an empty category, an unassigned ticket, a ticket without comments, tied timestamps and agents whose tickets are all unresolved.
- Submit an ER diagram, models and migrations, sample data, report queries and tests for constraints, edge cases and rollback. Each student keeps their own SQL and ORM examples for the shared reports.
- Independently explain one modeling choice and implement one unseen change during review. Example: add an optional due date and report overdue open tickets by agent, retaining agents with zero overdue tickets.
