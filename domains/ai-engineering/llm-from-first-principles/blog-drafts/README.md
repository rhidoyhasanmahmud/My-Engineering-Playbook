# Substack — Learning in Public

Write **one evidence-based weekly article** rather than publishing daily for its own sake.

## Article template

1. The problem or question
2. Intuition in plain English
3. Mathematics and implementation
4. What I tested (hardware, software versions, dataset, method)
5. Results and limitations (no fabricated benchmarks)
6. What surprised me or I misunderstood
7. What comes next
8. GitHub source links and references
