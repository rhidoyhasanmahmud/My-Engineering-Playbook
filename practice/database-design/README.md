# Database design practice

[Practice index](../README.md) · [Study roadmap](../../roadmaps/database-engineering.md)

- [Before-SQL capstone: library loans](before-sql-capstone.md): a guided design exercise with sample data, expected outcomes and a collapsible answer guide. Follow the [foundation roadmap](../../roadmaps/database-foundations.md) first; no installation or SQL is needed.
- [Design scenarios](scenarios.md): student enrolment, hotel booking, online exams, a job portal and food delivery.
- [Review questions](review-questions.md): the original database topic checklist, preserved for revision.

The design scenarios and original review questions are draft prompts. For each scenario, state requirements, draw relationships, choose keys and constraints, and discuss one design trade-off. Those broader scenario prompts do not yet include worked solutions; the before-SQL capstone has its own answer guide.
