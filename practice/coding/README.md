# Coding exercises

[Practice index](../README.md) · [Study roadmap](../../roadmaps/coding-practice.md)

Start with [common string problems](01-common-string-problems.md). The collection contains ten problems: reversal, palindrome, anagram, first non-repeating character, character counts, duplicate removal, space replacement, case conversion, rotation and comparison.

Java and Python solutions are included as draft learning examples. State assumptions, try edge cases and analyse complexity before using a solution as a reference.
