# My Engineering Playbook

A domain-first knowledge base for continuous engineering learning, hands-on practice, and reusable technical notes.

## Domains

- [Database Engineering](domains/database-engineering/README.md) — database concepts, courses, internals, case studies, and interview preparation.
- [Cloud Engineering](domains/cloud-engineering/README.md) — cloud architecture, services, and practical learning.
- [AI Engineering](domains/ai-engineering/README.md) — AI systems, models, and applied engineering.

## How this repository works

Each domain owns its learning material and practical knowledge. Learning notes are organized by source; reusable technical explanations live in their relevant domain sections. Add folders only as content grows.
