## Practice routine

1. Restate the input, output and assumptions.
2. Work through a small example by hand.
3. Write your solution before reading the supplied answer.
4. Try empty input, repeated values and boundary cases. Decide whether Unicode or `null` belongs to the scope.
5. Explain complexity and one alternative.
6. Record mistakes in your [study tracker](../templates/study-tracker.md).

The existing solution collection is draft material, not a tested programming library. A dedicated explanation of complexity is planned; meanwhile, include your own analysis for each solution.
