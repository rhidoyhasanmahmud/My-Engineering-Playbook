# Learning roadmaps

[Home](../README.md) · [Notes](../notes/README.md) · [Practice](../practice/README.md)

Choose a track that matches your goal. The steps are self-paced: move on when you can explain the idea and complete the checkpoint, rather than after a fixed number of days.

## Suggested starting route

| Stage | Focus | Outcome | Where to start |
| --- | --- | --- | --- |
| 1 | Backend foundations | Explain how clients and services communicate | [Backend fundamentals](backend-fundamentals.md) |
| 2a | Database foundations, before SQL | Model records, keys and relationships; explain normalization | [Database foundations](database-foundations.md) |
| 2b | SQL and database engineering | Explain transactions, storage choices and query performance | [Database engineering](database-engineering.md) |
| 3 | Cloud foundations | Reason about availability, cost and deployment choices | [AWS & cloud](aws-cloud.md) |
| Alongside any stage | Problem solving | Write a solution, test edge cases and discuss complexity | [Coding practice](coding-practice.md) |

Already comfortable with a stage? Use its checkpoints to identify gaps. These are independent tracks with prerequisites; you do not need to finish every planned topic before switching tracks.

**Completely new to databases? [Start the beginner course →](../notes/database-engineering/foundations/README.md)** It has no backend or programming prerequisite. Open Lesson 1 and follow the Next lesson links; the examples build on each other.

## How to follow a track

1. Check the prerequisites.
2. Open the note for the next available step.
3. Write a short explanation, try the example and answer the questions.
4. Complete the practical checkpoint without copying the answer.
5. Record questions and revisit weak areas in your own [study tracker](../templates/study-tracker.md).

**Structured** means a note follows the seven-section format. **Draft** means material exists and needs further review. **Planned** means the note has not been written. These labels describe repository coverage, not learner completion.
