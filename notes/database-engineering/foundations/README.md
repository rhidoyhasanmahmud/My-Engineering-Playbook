# Learn databases from zero

We will design a small system that remembers **students, courses and enrollments**. Start with a familiar problem and build the design one idea at a time.

**You need:** paper or a place to take notes. No coding experience, installation or SQL is required.

## Start here

**[Open Lesson 1: What is a database? →](01-what-is-a-database.md)**

For your first session, just complete Lesson 1. You do not need to read the whole roadmap today.

1. Read the explanation and the small example.
2. Try the question before opening its answer.
3. Use **Next lesson** when you can explain the answer. Use **Previous** whenever you need a reminder.

Use the sample records shown on each page for that page's exercise.

Each lesson has one main goal. The **Extra reading** box contains trade-offs, mistakes, interview questions and references; open it when you want more detail.

## Where this will take you

| Part | Your goal |
| --- | --- |
| Understand the data | Explain what the system remembers and organise it into tables |
| Connect and protect it | Identify students, connect them to courses and define valid changes |
| Complete a small design | Draw the model, reduce repeated facts and check your understanding |

You will finish with a model you can explain, ready to begin SQL. There is no fixed deadline; take another session when a practice question is difficult.
